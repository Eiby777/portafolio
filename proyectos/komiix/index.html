Editor web · Procesamiento de imágenes

Un espacio de trabajo para editar y traducir imágenes.

Desarrollé un editor que reúne las etapas de preparación, anotación, limpieza, traducción y salida de páginas. Combina interacción con canvas, gestión de proyectos y servicios de procesamiento de imágenes.

ProyectoKomiix
Mi aporte

Interfaz de edición, herramientas y gestión de estado, integración de modelos y OCR, servicios de backend y almacenamiento de proyectos.

El contexto

Del proceso a la aplicación.

Editar una página traducida implica trabajar sobre la imagen, extraer texto, limpiar el fondo y componer nuevos textos. Komiix organiza estas tareas en áreas de trabajo dentro del mismo editor.

Alcance desarrollado

Qué permite hacer.

Edición sobre canvas

Herramientas de interacción, zoom, capas y composición de texto sobre imágenes.

Etapas de trabajo

Áreas para original, anotación, limpieza, traducción y exportación.

Procesamiento de imágenes

Integración de detección, OCR e inpainting mediante modelos y servicios especializados.

Gestión de proyectos

Autenticación, almacenamiento local y componentes para organizar imágenes y recuperar proyectos.

Cómo lo construí

Las piezas del sistema.

El canvas y el estado de edición se gestionan en el frontend. FastAPI expone servicios de OCR y distribución de recursos para los modelos. El proyecto utiliza almacenamiento local del navegador para conservar información de trabajo.

  4. Editar composición
