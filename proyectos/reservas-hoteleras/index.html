Aplicación web · Integración de API

De la disponibilidad al comprobante de reserva.

Construí una aplicación que conecta una interfaz de gestión con los servicios de Veturis. El flujo incluye búsqueda de hoteles, confirmación de reservas, consulta de operaciones y generación de comprobantes.

ProyectoReservas hoteleras
Mi aporte

Frontend, endpoints de integración, transformación de mensajes XML, autenticación, persistencia y generación de vouchers.

El contexto

Del proceso a la aplicación.

Una API de reservas devuelve estructuras técnicas que el equipo necesita utilizar en su operación diaria. La aplicación reúne búsquedas, ocupación, políticas y datos de reserva en un flujo de trabajo accesible desde el navegador.

Alcance desarrollado

Qué permite hacer.

Búsqueda de disponibilidad

Fechas, ocupación, filtros y consulta de opciones de alojamiento a través de la integración.

Gestión de reservas

Formularios de confirmación, listado de operaciones y solicitud de cancelaciones.

Información estructurada

Modelos y funciones de transformación entre solicitudes de la aplicación y mensajes XML del proveedor.

Vouchers y acceso

Autenticación mediante Supabase y componentes para visualizar y generar comprobantes en PDF.

Cómo lo construí

Las piezas del sistema.

Organicé la integración en servicios de búsqueda y operaciones de reserva, con funciones para construir y analizar XML. El frontend trabaja con datos estructurados y componentes específicos para ocupación, filtros y comprobantes.
