# Portafolio de Abisay Medina

Portafolio estático de desarrollo full stack, automatización e IA. Incluye casos de estudio, muestras web, experiencia, servicios y contacto. Las capturas de las aplicaciones usan datos ficticios en entornos locales de demostración.

## Previsualizar

Desde esta carpeta ejecuta `python3 -m http.server 8000` y abre `http://localhost:8000/`. No requiere instalar dependencias para visualizar la web.

## Publicar en GitHub Pages

Revisa los cambios con `git status` y `git diff`, crea un commit con los archivos deseados y súbelo a la rama configurada como fuente de GitHub Pages. La publicación depende de la configuración del repositorio en GitHub. Las rutas están preparadas para `/portafolio/` y también funcionan con un servidor local.

La portada está en `index.html`, los casos en `proyectos/`, la galería anterior en `webs/` y las muestras en `sites/`. Los estilos y el comportamiento nuevos están en `assets/css/site.css` y `assets/js/site.js`.

El caso de cotizaciones documenta una experiencia previa. La aplicación original no está disponible y se plantea su recreación según los requisitos del proyecto. Las capturas de Veturis y el SaaS se generaron con respuestas de API simuladas. La imagen de Komiix utiliza una ilustración de muestra creada para el portafolio.
